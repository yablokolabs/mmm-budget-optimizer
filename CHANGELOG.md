# Changelog

## v1.0.0

### Skill
- `SKILL.md`: build engine → prepare data → fit with holdout gate → optimize within bounds → report
- `scripts/prepare_data.py`: daily or long-format data to weekly CSV, with checks for gaps, negatives, constant channels and history length
- `scripts/report.py`: accuracy, channel table (share, total ROI, marginal ROI, carryover, curve shape), recommended budget, forecast, caveats
- `references/`: data format, method, accuracy on known-answer data, limits
- `examples/`: 3 years of synthetic weekly data with known answers, plus `grade.py`

### Engine
- Needs [mmm-engine v0.2.0](https://github.com/yablokolabs/mmm-engine/releases/tag/v0.2.0)+ (`fit`, `optimize`, spend-aware `forecast`)
